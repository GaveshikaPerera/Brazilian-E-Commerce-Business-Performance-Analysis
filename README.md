# Brazilian E-Commerce Business Performance Analysis

## Project Overview

This project analyzes Brazilian e-commerce data to explore sales performance, product category revenue, customer distribution, and order fulfillment. Using MySQL and Excel, the project aims to identify business trends and generate insights that can support data-driven decision-making.

## Tools & Technologies

MySQL: Data quality checks, SQL joins, aggregations, grouping, sorting, and business analysis
Microsoft Excel 365: Data tables, charts, and reporting

## Business Questions

This project explores the following questions:

1. How do order volumes and revenue change over time?
2. Which product categories generate the highest revenue?
3. Which products have the highest sales volumes?
4. Which Brazilian states account for the most orders?
5. What is the distribution of orders by status?
6. What is the average order value?
7. How long does delivery take on average?
8. What percentage of delivered orders arrive late?

## Key Findings

- Peak order month: November 2017, with 7,544 orders.
- Top revenue-generating category: Beauty & Health (beleza_saude), generating approximately R$1.26 million in product revenue.
- Leading customer state: São Paulo (SP), with 41,746 orders.
- Average order value: Approximately R$137.75, based on product prices excluding freight.
- Average delivery time: Approximately 12.09 days.
- Late delivery rate: Approximately 8.11% of delivered orders with valid delivery dates.

## Project Workflow

1. Data Quality Checks — Examined record counts, duplicate product records, unique identifiers, and missing values.
2. SQL Analysis — Used aggregation, joins, date functions, subqueries, and conditional calculations to answer business questions.
3. Excel Reporting — Organized query results into tables and charts for monthly sales, category revenue, top-selling products, customer states, and order statuses.

## Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist, available on Kaggle.
Dataset source: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
The dataset contains information about orders, customers, order items, products, payments, reviews, sellers, and delivery.
